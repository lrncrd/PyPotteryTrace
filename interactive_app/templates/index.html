📖 How to Use PyPotteryTrace Interactive

1. Upload Image

Click the upload area to select a pottery drawing image.

2. Segment Elements

Point Mode: Click on the object to segment. Use positive (➕) clicks for the object and negative (➖) to exclude areas.

Box Mode: Draw a bounding box around the object.

3. Assign Category & Vectorization

Select the category and check/uncheck "Enable vectorization" to choose between SVG (vector) or PNG (raster with transparent background) output.

Some categories have vectorization disabled by default (Decoration, Prospectus, Handle/Application).

4. Set Rotation Center (Optional)

For profiles, switch to Rotation Center mode and click to set the symmetry axis. Profiles will be automatically mirrored.

5. Export

Click "Export Segments" to generate a ZIP file containing SVG files for vectorized segments and PNG files with transparent backgrounds for raster segments.

⌨️ Keyboard Shortcuts

  • P - Point Mode
  • B - Box Mode
  • R - Rotation Center Mode
  • Ctrl+Z - Undo
  • + - Zoom In
  • - - Zoom Out
