PyPotteryTrace — User Guide

Project Management

1

Create New Project

Click "New Project" to create a new pottery analysis project. Give it a name and description, then choose an icon.

2

Load Existing Project

Click on any project card to load it. The project name will appear in the header and info bar.

3

Project Organization

Each project maintains its own images, segmentations, and vectorized outputs. Files are automatically organized in the project folder.

Setup

1

Create or Open a Project

Use the Project Manager to create a new project or open an existing one. Supported formats: PNG, JPG, JPEG, TIFF, BMP.

2

Choose SAM2 Model

Select model size based on your hardware and requirements:

  • Tiny: Fastest, good for quick tests (~40MB)
  • Small: Recommended for most workflows (~180MB)
  • Base+: Higher precision, moderate speed (~230MB)
  • Large: Highest precision, best for complex profiles (~900MB)

Segmentation Workflow

1

Choose Segmentation Mode

Point Mode: Click to add positive or negative points. SAM2 will segment the object based on your clicks.

Box Mode: Draw a bounding box around the object for automatic segmentation.

Polygon Mode: Manually draw a polygon mask by clicking vertices.

Edit Mask: Convert mask to an editable polygon to fine-tune vertices.

Rotation Center: Set the symmetry axis for profile mirroring.

2

Assign Category

Select the appropriate category for the segmented element (Profile, Application, Handle, Prospectus, Decoration, Running element, Detail).

3

Export

Click "Generate SVG" to create the vectorized output and switch to SVG Editor for path refinement.

SVG Editor

1

View Mode

Pan and zoom to navigate the SVG canvas. Reposition reference layers as needed.

2

Select & Edit Points

Select points individually or multi-select with Shift. Drag points to adjust profile curves precisely.

3

Add & Delete Points

Add new points along existing paths to increase fidelity, or delete redundant points to simplify contours.

Post-Processing

1

Batch Export

Convert and standardize your vectorized drawings into publication formats (SVG, 300 DPI transparent PNG, JPG).

2

Stroke Customization

Configure stroke widths according to classical ceramic drawing conventions (profile thicker, decoration and construction lines lighter).
